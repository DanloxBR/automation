# 🤖 Automation | RPA em Java com Selenium

Projeto de **Automação de Processos (RPA)** desenvolvido em **Java**, utilizando **Selenium WebDriver**, com foco na automação de tarefas repetitivas, validações e fluxos em aplicações web.

Este repositório faz parte do meu **portfólio profissional**, demonstrando conhecimentos práticos em **Java**, **automação**, **boas práticas de código** e **organização de projetos**.

---

## 📌 Visão Geral

A automação é estruturada para ser **escalável**, **organizada** e **fácil de manter**, utilizando conceitos fundamentais de **Programação Orientada a Objetos** e padrões comuns no desenvolvimento de bots RPA.

O projeto foi pensado para simular cenários reais enfrentados no dia a dia de automação e testes automatizados.

---

## 🚀 Tecnologias & Ferramentas

- **Java**
- **Selenium WebDriver**
- **Maven**
- **Git & GitHub**
- **Padrão Factory (DriverFactory)**
- **ExpectedConditions (Waits explícitos)**

---

### 📂 Principais Componentes

- **DriverFactory**  
  Responsável pela criação e gerenciamento do WebDriver, centralizando a configuração do navegador.

- **Main**  
  Classe principal que executa o fluxo de automação, realizando navegação, interações e validações.

---

## ⚙️ Funcionalidades Implementadas

- Inicialização controlada do WebDriver
- Navegação automatizada em páginas web
- Interação com elementos (inputs, botões, links)
- Uso de **esperas explícitas** para maior estabilidade
- Estrutura preparada para expansão de novos fluxos RPA

---
